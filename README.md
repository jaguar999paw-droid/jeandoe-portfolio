# Jean Doe — adoptable portfolio template

Demo/template site built entirely on CSS3 custom properties (design
tokens) — re-theme the whole page by editing one `:root` block.
Frontend on the personal-plane platform — see
[portfolio-gateway](https://github.com/jaguar999paw-droid/portfolio-gateway).

**Live:** https://jeandoe-portfolio.pages.dev

## Local dev
```
npm install && npx wrangler pages dev .
```
## Deploy
```
npx wrangler pages deploy .
```
